# Planting calendar

This calendar turns the recurring shallow-planter rotation into upcoming work.

<div class="calendar-note">
<strong>Calendar semantics:</strong> the source plan defines <em>start weeks</em> (`wwXX`), not exact days. A <strong>final harvest</strong> shown here is derived from the rotation boundary: finish and clear the outgoing crop in the same ISO week, immediately before sowing the incoming crop. The displayed Monday–Sunday range is therefore a working window, not a fixed appointment.
</div>
